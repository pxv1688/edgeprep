25Python: what does print(-17 // 4) show?

Python arithmeticInterview

Show the answer and solution

Answer: -5

// is floor division: it divides, then rounds down toward −∞ (not toward zero). -17 / 4 = -4.25, which rounds down to -5. Watch out: rounding toward zero would give -4.

26Python: what does print(-17 % 4) show?

Python arithmeticInterview

Show the answer and solution

Answer: 3

Python defines a % b = a − b × (a // b), so the result takes the sign of b. Here -17 // 4 = -5, so -17 % 4 = -17 − (4) × (-5) = 3.
